# UTP Marketplace

Proyecto final desarrollado para el curso Hojas de Estilo en Cascada Avanzado. UTP Marketplace es una plataforma web diseñada para la comunidad universitaria, permitiendo el intercambio y venta de artículos (libros, electrónica, proyectos) entre estudiantes.

## Características principales
- **Diseño Responsive:** Implementación de Bootstrap 5 para una interfaz adaptable.
- **Arquitectura Modular:** Uso de SASS con estructura de carpetas profesional (_variables, _mixins, _components).
- **Catálogo Dinámico:** Carga de productos mediante JavaScript y JSON.
- **Funcionalidad de Carrito:** Almacenamiento temporal de productos seleccionados utilizando `localStorage`.
- **Efectos Visuales:** Aplicación de transiciones, transformaciones y animaciones según los requisitos del proyecto.

## Tecnologías utilizadas
- **HTML5**
- **SASS** (Preprocesador CSS)
- **Bootstrap 5** (Framework CSS)
- **JavaScript** (Lógica funcional)
- **Node.js** (Gestión de dependencias y compilación de SASS)
